# Changelog: Redis

> version: $Id$ ($Date$)

## History

0.1.0-dev @2025 Apr xx

- new: `Redis` Redis client for Inane\Stdlib
- new: `Redis::get` Get value from redis
- new: `Redis::set` Set value in redis
- new: `Redis::delete` Delete value from redis
- new: `Redis::exists` Check if key exists in redis
- new: `Redis::expire` Set expiration time for key in redis
- new: `Redis::keys` Get all keys matching a pattern in redis
- new: `Redis::flushdb` Flush the current database in redis
- new: `Redis::flushall` Flush all databases in redis
